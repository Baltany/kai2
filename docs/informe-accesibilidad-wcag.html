Principio Implementación en Kairos

  • Spinners en botones durante operaciones asíncronas

  • Lenguaje español natural sin jerga técnica

  • Fechas en formato español: "15 de noviembre de 2023"
  • Precios en formato europeo: "59,99 €"
3. Control y libertad del usuario
  • Confirmación antes de eliminar usuarios
  • Botones "Cancelar" en todos los formularios
  • Skip link para usuarios de teclado
  • Modales cerrables con X, Esc o click fuera
  • Logout siempre accesible en navegación
4. Consistencia y estándares
  • Bootstrap 5.3.8 en toda la aplicación
  • Variables SCSS: $primario, $secundario, $resalte
  • Sistema de espaciado modular (8, 16, 24, 32, 40px)
  • Jerarquía tipográfica: H1 (2.5rem), H2 (2rem), H3 (1.5rem)
  • Header y footer idénticos en todas las páginas
5. Prevención de errores
  • Validación HTML5: required, type="email", minlength
  • Validación JavaScript en tiempo real (validaciones.js)
  • Validación backend robusta (regex, tipos, rangos)
  • Atributos autocomplete para reducir errores de escritura
  • inputmode="numeric" para campos numéricos en móvil
  • Patterns: pattern="[0-9]{9}" para teléfonos
  • CAPTCHA en registro y contacto
6. Reconocimiento antes que recuerdo
  • Placeholders con ejemplos: placeholder="ejemplo@correo.com"
  • Helper text bajo cada input con formato esperado
  • Valores por defecto en formularios de edición
  • Iconos + texto en botones: "🛒 Añadir al carrito"
  • aria-current="page" en navegación activa
7. Flexibilidad y eficiencia
  • Skip link para usuarios de teclado avanzados
  • Validación en tiempo real para usuarios expertos
  • Validación paso a paso para usuarios novatos
  • Componentes responsive adaptados a cada dispositivo
8. Diseño estético y minimalista
  • Jerarquía visual clara: títulos grandes, texto cuerpo pequeño
  • Espaciado generoso (sistema 8px)
  • Paleta limitada: 4 colores principales + neutros
  • Tipografía legible: sans-serif, tamaño base 16px
  • Sin elementos superfluos: solo información necesaria
9. Ayuda con errores
  • Mensajes de error específicos y constructivos
  • "El teléfono debe tener exactamente 9 dígitos (ej: 612345678)"
  • Sugerencias de corrección incluidas en los mensajes
  • Feedback visual (rojo) + textual
  • Links de ayuda cuando aplica ("¿Olvidaste tu contraseña?")
